# MemphisOS — Archived

> **This repository has been consolidated into [Memphis](https://github.com/Elathox/memphis).**
>
> All source code, tests, CI workflows, and documentation now live in the Memphis repository.
> Memphis is the single canonical repo for the secure agent runtime and control plane.

## Why

Memphis and MemphisOS shared 98% of their codebase. Maintaining both caused duplicated work, divergent tests, and code leaking between repos. As of 2026-03-15, Memphis is a strict superset of MemphisOS — every source file, test, dependency, and workflow exists in Memphis.

## What to do

- **Clone Memphis instead:** `git clone https://github.com/Elathox/memphis.git`
- **Report issues on Memphis:** https://github.com/Elathox/memphis/issues
- **All commands remain the same:** `memphis doctor`, `memphis config tools`, etc.

This repository is archived and will receive no further updates.
